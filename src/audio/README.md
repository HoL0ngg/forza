# Âm thanh động cơ

`engine-audio.ts` tổng hợp động cơ sáu xi-lanh bằng oscillator/noise. Nhận RPM, throttle, trạng thái ly hợp, rev-match và sự kiện sang số từ Game. AudioContext khởi chạy sau tương tác, suspend khi tạm dừng/mute, dispose khi rời trang. M bật/tắt; Esc chỉnh âm lượng. Không có asset tải ngoài hoặc mẫu thu động cơ thật. Xem README gốc để chạy và kiểm tra.
