# Tuning động cơ và hộp số

`tuning.ts`: defaultConfig, clone, validation, torque curve nội suy, chuyển RPM/tốc độ và thống kê công suất. `storage.ts`: một preset JSON có version trong localStorage, kiểm tra dữ liệu và fallback. Giao diện riêng tại `ui/tuning-panel.ts`; G mở bảng, chỉ Áp dụng mới thay cấu hình xe. Xem README gốc để biết giới hạn và cách thử.
